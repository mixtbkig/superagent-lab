这不是 API 手册，而是一趟由浅入深的旅程：我们先看懂 Claude Code、Codex 这类 agent harness 到底在替大模型做什么， 再一层层走进 DeepSeek Harness 的源码——Cordis 插件框架、Agent 主循环、会话语义、工具流水线、上下文压缩、 多智能体编排与前端传输。每一个抽象概念，都配一张图或一段可以点的动画。

🧭 这份教程怎么读（推荐顺序）
  1. 先建直觉（第 0–3 章）：弄明白「harness 是什么」「Agent 循环怎么转」「插件框架怎么拼」。不要跳过第 2、3 章，它们是后面所有内容的钥匙。
  2. 再读引擎（第 4–9 章）：一次请求如何从 UI 走到模型再走回来；会话日志、轮次、LLM、工具这两大核心。
  3. 然后补上下文与编排（第 10–14 章）：记忆、压缩、持久化、子代理、技能与 MCP。
  4. 最后看外围与全景（第 15–20 章）：审批、前端、安全、全部模块清单，以及动手写一个插件。

每一章都有：🧸 小学生版比喻 → 原理讲解 → 可交互图示 → 源码坐标 → 小测验。读完后点「标记本篇已学完」，进度会保存在你的浏览器里。

你会得到什么
🧠

一张正确的心智模型

知道「模型 / harness / 工具 / 上下文 / 会话」各是什么，以及它们如何协作，而不是死记 API。

🔍

能自己读源码

每章都给出真实文件路径与行号。学完你能顺着 docs/architecture.md 和 packages/ 自己往下挖。

🧩

会写插件

理解 Cordis 的注册与副作用后，你能给 DSH 加一个工具、一个事件监听器，甚至一个 LLM 适配器。

⚖️

看懂设计取舍

为什么事件溯源？为什么一切皆插件？为什么沙箱要 fail-closed？这些「为什么」比「是什么」更重要。

本教程基于 GitHub 仓库 deepseek-ai/deepseek-harness（master 分支，仓库自带丰富的中文文档）。所有结论都能在 docs/ 与 packages/ 中找到出处。教程用通俗语言重新组织、配图与动画，方便从头学起；遇到细节请以源码为准。
